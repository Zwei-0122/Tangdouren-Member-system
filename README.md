# 糖豆人手工工作室 官网 + 糖豆人会员系统

这是 [糖豆人手工工作室官网](https://github.com/KeMiaoDaDi/Tangdouren) 的一份完整副本，包含 **糖豆人会员系统**的完整实现。克隆下来装好依赖、填好环境变量、在 Supabase 执行两个迁移，就能在本地跑起来。

技术栈：Next.js 16（App Router）、TypeScript、Supabase、Tailwind CSS。

## 会员系统做了什么

- 会员身份：邮箱即身份，不设密码；顾客扫桌上的二维码即可加入或登录，设备会记住身份
- 到店进度：按伦敦自然日去重，同一天多次到店只算 1 次
- 奖励引擎：每 10 个计入进度的到店为一轮，第 2 次发 £2 抵用券、第 5 次 £5、第 8 次本人 85 折加朋友 9 折、第 10 次 VIP 月卡（店主的规则文档里叫 VIP Month）；第二轮门槛落在 12 / 15 / 18 / 20
- VIP 月卡：30 天（含首尾），不自动激活、不自动续期。生效期间每次计时自动 85 折，**到店进度照常累积**、其他奖励不失效；柜台也可手动改用某张券或会员奖励，但不允许按原价结账
- 到店归属：扫桌码时填注册邮箱就归到本人名下；顾客忘了填，店员可在后台把这张单补挂到会员（已结算的单只加「累计到店」、不加「奖励进度」，已收金额不动）
- 英文版：**暂不开放会员制度**。会员入口与预约页的加入勾选框只在中文界面出现，英文提交在服务端也会被拦下
- 结算接入：店员在结算面板选择会员奖励，金额由服务端计算并复核，撤销结算可回退未使用的奖励

## 怎么跑起来

先读 **[docs/会员系统交付说明.md](docs/会员系统交付说明.md)**，里面有完整步骤、口径解释、验证情况和未完成项。三步概览：

```bash
# 1. 环境变量（不进仓库）
#    建 .env.local，填 NEXT_PUBLIC_SUPABASE_URL / NEXT_PUBLIC_SUPABASE_ANON_KEY /
#    SUPABASE_SERVICE_ROLE_KEY / NEXT_PUBLIC_APP_URL

# 2. 把 supabase/migrations/016_members.sql 与 017_member_settlement.sql
#    按顺序在 Supabase 的 SQL Editor 里执行一次（顺序不能反）

# 3. 起服务（用 localhost，不要用 127.0.0.1）
npm install
npm run dev -- -p 3002
```

验证：

```bash
node --experimental-strip-types --test tests/member.test.ts
npx tsc --noEmit
npm run build
```

另有三份验收脚本，都在 `docs/`：

- `verify_member_system.sql`：数据库层断言，全程一个事务，最后 ROLLBACK，不留数据
- `verify_via_api.py`：走真实库的 64 项规则校验（VIP 日期边界、券核销与撤销回退、补挂规矩等）
- `场景演练_via_api.py`：按店里真实流程走一遍的 96 项演练（散客不填邮箱、同一天来两次、跨夜单、忘填邮箱补挂、用券、撤销、VIP 到期、20 次老顾客、顾客页看到什么），跑完自动清场
